## 1. Introdução

Este documento detalha as classes, métodos e endpoints necessários para implementar as funcionalidades de **cadastro de um novo Pet** e o subsequente **cadastro da sua Carteirinha de Vacinação**, seguindo a arquitetura em camadas do projeto.

---

## 2. Fluxo de Cadastro de Pet

O primeiro passo é permitir que um Tutor (usuário) cadastre um novo animal de estimação.

### 2.1. Endpoint

*   Verbo: POST
*   Caminho: /pets
*   Descrição: Cria um novo registro de Pet associado ao Tutor logado.

### 2.2. DTO: PetDTO.java

Este objeto será o corpo (body) da requisição POST /pets.

| Campo     | Tipo     | Exemplo             | Obrigatório |
| :-------- | :------- | :------------------ | :---------: |
| tutorId | UUID     | "uuid-do-tutor"   |      ✅      |
| nome    | String   | "Bolinha"         |      ✅      |
| especie | String   | "Cachorro"        |      ✅      |
| raca    | String   | "Vira-lata"       |      ✅      |

### 2.3. Controller: PetController.java

Responsável por receber a requisição e orquestrar a chamada para a camada de serviço.

```bash
@RestController
@RequestMapping("/pets")
public class PetController {

    @Autowired
    private PetService petService;

    @PostMapping
    public ResponseEntity<Pet> createPet(@RequestBody PetDTO petDto) {
        Pet novoPet = petService.create(petDto);
        return new ResponseEntity<>(novoPet, HttpStatus.CREATED);
    }
}
```

### 2.4. Service: PetService.java

Contém a lógica de negócio principal.

```bash
@Service
public class PetService {

    @Autowired
    private PetRepository petRepository;

    @Autowired
    private TutorRepository tutorRepository; // Para buscar o tutor

    public Pet create(PetDTO petDto) {
        // 1. Validar se o tutorId existe
        Tutor tutor = tutorRepository.findById(petDto.getTutorId())
            .orElseThrow(() -> new RuntimeException("Tutor não encontrado!"));

        // 2. Mapear DTO para Entidade
        Pet pet = new Pet();
        pet.setNome(petDto.getNome());
        pet.setEspecie(petDto.getEspecie());
        pet.setRaca(petDto.getRaca());
        pet.setTutor(tutor);

        // 3. Persistir no banco
        return petRepository.save(pet);
    }
}
```

## 3. Fluxo de Cadastro de Carteirinha de Vacinação

Uma vez que o Pet existe, é possível criar e associar sua carteirinha de vacinação.

### 3.1. Endpoint

*   Verbo: POST
*   Caminho: /pets/{petId}/vaccination-card
*   Descrição: Cria uma carteirinha de vacinação para um Pet específico.

### 3.2. DTO: VaccinationCardDTO.java

Corpo da requisição para a criação da carteirinha.

| Campo          | Tipo            | Exemplo                     | Obrigatório |
| :------------- | :-------------- | :-------------------------- | :---------: |
| dataEmissao  | Date            | "2024-05-21"              |      ✅      |
| vacinas      | List<String>    | ["Raiva", "V10"]        |      ❌      |


### 3.3. Controller: VaccinationCardController.java

```bash
@RestController
@RequestMapping("/pets/{petId}/vaccination-card")
public class VaccinationCardController {

    @Autowired
    private VaccinationCardService cardService;

    @PostMapping
    public ResponseEntity<Carteirinha> createCard(@PathVariable UUID petId, @RequestBody VaccinationCardDTO cardDto) {
        Carteirinha novaCarteirinha = cardService.create(petId, cardDto);
        return new ResponseEntity<>(novaCarteirinha, HttpStatus.CREATED);
    }
}
```

### 3.4. Service: VaccinationCardService.java

```bash
@Service
public class VaccinationCardService {

    @Autowired
    private VaccinationCardRepository cardRepository;

    @Autowired
    private PetRepository petRepository; // Para buscar o pet

    public Carteirinha create(UUID petId, VaccinationCardDTO cardDto) {
        // 1. Validar se o petId existe
        Pet pet = petRepository.findById(petId)
            .orElseThrow(() -> new RuntimeException("Pet não encontrado!"));

        // 2. Mapear DTO para Entidade
        Carteirinha carteirinha = new Carteirinha();
        carteirinha.setDataEmissao(cardDto.getDataEmissao());
        carteirinha.setVacinas(cardDto.getVacinas());
        carteirinha.setPet(pet);

        // 3. Persistir no banco
        return cardRepository.save(carteirinha);
    }
}
```
